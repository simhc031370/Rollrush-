# 교실 구슬 추첨기

수업 중 발표자, 당번, 모둠을 뽑기 위한 **오프라인 구슬 추첨기**입니다. 브라우저에서 `index.html`만 열면 됩니다. 광고, 로그인, 외부 추적 스크립트는 없습니다.

## 원본 마블 룰렛에서 가져온 아이디어

[Marble Roulette](https://lazygyu.github.io/roulette/) 공개 페이지의 UI 스크립트를 분석한 뒤, **같은 수업 시나리오를 우리 쪽으로 다시 구현**했습니다. 원본의 맵 데이터, 스프라이트, Box2D 빌드, 상점/광고/분석 코드는 가져오지 않았습니다.

원본이 실제로 하던 일:

| 기능 | 원본 동작 | 이 앱 |
| --- | --- | --- |
| 명단 입력 | 쉼표/줄바꿈 분리, `이름*개수`, `이름/가중치` | 동일 문법으로 자체 파서 구현 |
| 준비/출발 | 명단이 있을 때만 Start, Shuffle이 구슬을 다시 배치 | 동일 |
| 당첨 방식 | 1등 / 꼴등 / N등 / 구간 | 동일 (0-based 범위를 내부에서 계산) |
| 맵 | Box2D 스테이지 여러 개 | 칠판 미끄럼, 뽑기 칠판, 과학실 톱니 (자체 지형) |
| 스킬·테마·녹화 | 옵션 토글 | 옵션 토글 (Web Audio / MediaRecorder) |
| 저장 | `localStorage`에 명단 저장 | 명단 + 설정 + 최근 결과 |
| 광고·샵·UMAMI/GA | 있음 | **없음** |

교실에서 바로 필요해서 더한 것:

- **당첨자 제외** — 이미 뽑힌 학생은 다음 라운드에서 빠지고, 칩을 눌러 되돌릴 수 있습니다.
- 프로젝터용 큰 당첨 화면, 전체 화면, 한/영 전환.
- 의존성 없는 정적 파일. USB에 복사해도 됩니다.

## 수업에서 쓰는 법

1. 폴더를 연 뒤 터미널에서 `npm start` 또는 `python3 serve.py`를 실행하고 http://localhost:4173 을 엽니다. `serve.py`는 IPv4와 IPv6를 같이 열어서 Chrome이 `localhost`를 `::1`로 붙일 때도 연결됩니다. 모듈 스크립트를 쓰므로 `index.html`만 더블클릭하면 막힐 수 있습니다.
2. 왼쪽 명단에 학생 이름을 한 줄에 한 명씩 붙입니다.
3. **출발**을 누릅니다. 구슬이 골인 선을 통과한 순서가 순위입니다.
4. 여러 명을 뽑을 때는 당첨을 **여러 명**으로 두고 구간을 정합니다.
5. 한 명씩 계속 뽑을 때는 **당첨자 제외**를 켜 두세요.

단축키: `Space` 출발, `S` 섞기, `F` 전체 화면. 경기장을 길게 누르면 배속입니다.

### 이름 문법

```
민준
서연*2      ← 구슬 2개 (기회 2배)
하준/3      ← 가산점. 구슬이 조금 크고 스킬 확률이 올라갑니다
지유/2*3    ← 가산점 2, 구슬 3개
```

## 개발

```bash
npm test
npm start
```

물리 엔진은 원 대 선분/원 충돌만 다루는 가벼운 2D 구현입니다. 맵은 `js/maps.js`에서 바꿉니다.
